# 우리 가족 달력 (테스트 버전)

가족 6명(아빠·엄마·외할머니·첫째·둘째·막내)이 함께 쓰는 모바일 웹앱(PWA)의 테스트 버전입니다.
`https://anarita82.github.io/family-calendar/` 에서 열 수 있습니다.

## 지금 되는 것

- 월간 달력(월 이동·오늘 버튼·날짜별 색상 점), 선택일 일정 상세, 다가오는 일정 D-Day
- 구성원 필터 칩(전체 / 6명)과 일정별 담당 가족 배지
- 일정 추가·수정·삭제: 제목, 날짜, 시간(종일 가능), 담당 가족(복수), 카테고리 5종, 메모
- 반복: 없음 / 매년 양력 / 매년 음력 (음력은 보는 해의 양력 날짜로 자동 계산, 음력 날짜 병기)
- 공휴일 표시(설날·추석 연휴, 부처님오신날, 고정 공휴일, 대체공휴일 계산) — 일요일 빨강, 토요일 파랑
- 일정은 브라우저 `localStorage`에만 저장, 테스트 데이터 초기화 버튼
- PWA: `manifest.json`, 앱 아이콘, `/family-calendar/` 범위의 서비스 워커

## 테스트 버전의 한계

- 일정은 **이 기기의 브라우저에만** 저장됩니다. 가족 간 공유는 아직 없습니다(공유 DB 연결 예정).
- 음력 변환은 내장 데이터(2022~2040년, 한국천문연구원 기준 음력 데이터)로 계산합니다. 범위를 벗어난
  날짜는 음력 반복으로 저장할 수 없습니다.
- 대체공휴일은 "주말과 겹치는 공휴일 → 다음 평일" 규칙으로 계산합니다. 두 공휴일이 같은 날에
  겹치는 경우(예: 2025-05-05)와 선거일 외의 임시공휴일은 반영하지 않습니다.
- 샘플 일정은 모두 `[샘플]`로 시작하는 테스트 데이터입니다. 실명·생년월일·연락처는 넣지 않았습니다.

## 파일

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 구조 |
| `styles.css` | 모바일 퍼스트 카드형 스타일 |
| `lunar.js` | 한국 음력↔양력 변환, 공휴일 계산 |
| `app.js` | 상태·렌더링·일정 저장(localStorage) |
| `manifest.json` / `sw.js` / 아이콘 | PWA 설치·오프라인 캐시 |
